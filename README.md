# 蜜雪冰城 · 点单模拟 App

> 一个手机端风格的蜜雪冰城点单**模拟**演示 —— 支持购物车、模拟微信支付、播放主题曲，以及一个酷炫的 **液态玻璃开关**。

## ✨ 功能特性

- 🧋 蜜雪冰城经典菜单：珍珠奶茶、草莓摇摇奶昔、芋圆葡萄、摩天脆脆、小零食套餐，另有冰鲜柠檬水、满杯百香果、香芋奶茶、**安卓的樱桃派**（宽图完整展示，进详情自动播放专属音频）、**神秘猪妞**（木屑清香 · 毛毛茸茸）
- 🛒 完整购物车流程：加购、改数量、结算、模拟微信支付（密码 `123456`）
- 🕐 **状态栏时间与系统实时同步**（参考 time.is 口径）
- 🎵 打开珍珠奶茶详情页自动播放主题曲《你爱我我爱你》
- 🐽 **神秘猪妞 3D 预览器**：进入神秘猪妞的规格/选口味页面时，内置 **three.js 3D 预览器**实时预览猪妞绑骨版 FBX 模型（可拖动旋转 + 自动慢转），并自动播放专属音频《炸闺蜜.mp3》（复用珍珠奶茶的播放音乐代码）
- 🧲 **液态玻璃球旋钮**：底部栏与拖动小旋钮均为圆形（无橙色圆点）；按下时旋钮放大、变通透，像一颗玻璃球覆盖在文字上；速度越快玻璃球越大越通透，**且透明度随设置里的通透度联动**；**手指停止后才判定停靠页面**，并按「间隔页数 × 360°」旋转、带运动模糊到位
- ⚙️ **设置页**（顶部齿轮 / 我的-设置）：顶部有**玻璃通透度演示块**，收纳液态玻璃开关与通透度滑杆，可切换**浅色 / 深色模式**（不跟随系统，默认浅色），底部有**「更多玩法请访问 link3.cc/zhuniuwebs」**可点击跳转链接
- 💧 **液态玻璃**：所有页面、所有卡片与按钮（购买区、支付区、商品卡、结算条等）全部套用；**通透度可调**（拉高=极通透，拉低=毛玻璃）；**手指按压玻璃时光晕跟随手指**；CSS `backdrop-filter` + WebGL 实时叠加液态高光
- 🔐 **我的页登录**（纯前端演示）：仅登录、无注册，任意用户名与密码均可直接登录，刷新后保留
- 🎨 **图标全部使用 SVG**（不再依赖 emoji），商品图更丰富，观感更接近真实应用
- 📱 移动端优先，桌面端居中显示手机容器

## 🧪 本地运行

无需构建，直接打开或起一个静态服务器：

```bash
# 任选其一
python3 -m http.server 8080
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8080` 即可。
